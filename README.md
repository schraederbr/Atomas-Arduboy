# Attaboy
Unofficial port of the mobile game [Atomas by Sirnic Interactive](http://sirnic.com/atomas/) to the Arduboy

Play it [here](https://tiberiusbrown.github.io/Ardens/player.html?blah=https://raw.githubusercontent.com/schraederbr/Atomas-Arduboy/refs/heads/main/a_atomas/build/arduino.avr.leonardo/a_atomas.ino.hex&g=none&z=1&p=0&palette=highcontrast)

Use LEFT, RIGHT, A BUTTON, B BUTTON to play. A inserts the middle atom, B converts an atom to plus (when grabbed via minus)
